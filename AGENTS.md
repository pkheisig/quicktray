# QuickTray Agent Instructions

Follow the global AGENTS instructions for this workspace.

## Swift App Edits

- After making any code edit to this Swift/macOS app, rebuild the app bundle and copy it to `/Applications` before reporting the work as finished.
- For this project, use `./build.sh` from the repo root; it creates `build/QuickTray.app`, signs it, and installs it as `/Applications/QuickTray.app`.
- Still run `swift build` when useful for a fast compile check, but it does not replace the final app bundle rebuild and install step.
